# Sourav Raxit

## Running Locally

This is Sourav Raxit's academic website, built with Jekyll for GitHub Pages.

Install Ruby, Bundler, and Node.js, then run:

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

The local site will be available at `http://localhost:4000`.

## Content

* Home page: `_pages/about.md`
* Publications: `_pages/publications.md` (citation counts and metrics sourced from [Google Scholar](https://scholar.google.com/citations?user=zecw1dYAAAAJ&hl=en))
* Gallery: `_pages/gallery.md` — drop photos into `images/gallery/` and swap them into the placeholder tiles
* CV page: `_pages/cv.md`
* PDF CV: `files/My_Cv_final.pdf`
